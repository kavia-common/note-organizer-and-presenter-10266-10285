# Welcome to [Slidev](https://github.com/slidevjs/slidev)!

To start the slide show:

- `pnpm install`
- `pnpm dev`
- visit <http://localhost:3000>

Edit the [slides.md](./slides.md) to see the changes.

Learn more about Slidev at the [documentation](https://sli.dev/).

Notes App usage:

- Navigate to the "Notes App" slide in this deck to open the embedded UI.
- Or go to `#/present` hash route after creating a note and clicking "Present" to open the presentation view in a new tab.
